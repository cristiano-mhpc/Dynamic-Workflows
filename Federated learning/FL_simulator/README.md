### Federated Learning (FL) Simulator Skeleton

This repository provides a minimal Python framework for building a Federated Learning (FL) simulator.

**Getting Started:**

* Students are expected to implement the abstract classes found in `base_client.py` and `base_server.py`.
* A draft implementation of the FedAvg algorithm is provided in `base_fed_avg.py` as a starting point for custom scripts.

**Note:**

* The simulator runs sequentially by default. However, it can be parallelized or distributed using workflow- or task-based programming techniques.
